Scribecue needs a computer

It's an editor for audio description scripts, built for a keyboard and a big screen: you hold keys while the narrator speaks, step through the video frame by frame, and work on a timeline. That isn't possible on a phone or tablet.

Open scribecue.kyleadvoice.ca on a computer, in Google Chrome or Microsoft Edge.

    Welcome to Scribecue

    Scribecue is a keyboard-first editor for audio description scripts. Your video and your script stay on your computer: nothing is uploaded.

    This quick setup picks the tools you need. You can change any of it later, and run it again with Setup at the top.

    What are you working on?

    You can switch at any time with the Transcribe / Write switch at the top.

    Hold-to-mark

    Play the video, hold H while the narrator speaks a line, and let go when they stop. A block appears, ready for you to type the line.

    Both edges of a mark move back by this much, because your key press comes a moment after you hear the voice. 200 ms suits most people.

    Text to speech

    Hear each block read aloud, and see how long it takes to say, so you know it fits.

    Updates

    Scribecue can check GitHub once a day and tell you when a new version is out.

      Find and replace

      Sounds like

      Tell text to speech how to say words in this block. Only the reading changes: the block's text stays as written, in the list and in exports.

      Spell it how it sounds, such as shiv-AWN for Siobhan. Each word or phrase is matched as a whole word, in any case. Tip: select a word in the text box and click Sounds Like under it, or press ⌥⇧P, and it's filled in for you.

      Text to speech

      Hear blocks read aloud, to check where each line sits and whether it fits before the next piece of dialogue.

      This browser doesn't support text to speech.

      Natural voices Recommended

      Piper voices sound more natural, give exact lengths straight away, and let you export a description track. They run in your browser, so your script stays on your computer. Each voice is a one-time download, and then it works offline too.

      Applies to blocks you create with ↵ or N. Blocks marked with H, drawn on the timeline, opened from a file, or whose end you've set yourself keep their timing.

      Drag an edge, or use A, S, Q, W, E or R, and the reading speeds up or slows down to fill the block, shown as a custom speed. Picking a speed for the block yourself stops this.

      Update all timings

      Set the end of every block from how long its reading takes, with each block's own speed. This includes blocks marked with H and blocks opened from a file. Ends never run into the next block, and Z undoes it.

      Fit speeds to timings

      The other way round: every block keeps its timing, and its reading speeds up or slows down to fill it, between −50% and +100%. Useful for a script opened from a file. Blocks with a speed you picked keep it, and Z undoes it.

      Export description track

      Save every block's reading as one WAV file, each starting at its block's start time, ready to mix with the programme. Readings peak at −8 dBFS, leaving headroom for processing and mastering.

      Online voices

      This browser doesn't offer any online voices. To use them, open Scribecue in Microsoft Edge, which has the most, or Google Chrome. Safari and Firefox only have the voices on your computer.

      Online voices often sound more natural, but each block's text is sent to the company that runs the voice, such as Google or Microsoft, to be spoken. Leave this off if your script mustn't leave your computer. The voices built into your computer keep everything on it.

      Keys

      V read the selected block from its start · ⇧V set the block's end to where the reading finishes · [ ] this block slower / faster · ⌥⇧P how words in this block sound · ⌥⇧V this panel

      Did you know? Recommended

      Scribecue can use Piper, a free, open-source speech engine that runs next to it in Docker. Its voices sound much more natural, stay on your computer, and work offline. With a Piper voice, reading lengths are exact straight away, and you can export a description track as a WAV file.

      To add it, put COMPOSE_PROFILES=piper in a file called .env in the Scribecue folder, then run docker compose up -d --build and reload this page. More about Piper

        Remove all data

        Removes everything Scribecue keeps in this browser: unsaved blocks, settings and shortcuts, AI keys, downloaded Piper voices and Whisper, and its offline copy. Project and script files on your computer aren't touched, and neither is anything in Docker, such as Piper, Whisper or Ollama models.

        Speech to text

        Whisper listens to each block you mark with H and types what the narrator says, ready for you to check. You still time every line yourself. It runs on your computer, so the audio never leaves it.

        Whisper is a one-time download into your browser, and then it works offline too. It's fastest in Chrome or Edge on a computer with a graphics chip they can use.

        When you let go of H, the block's text appears after a moment. If you start typing first, Whisper leaves the block to you.

        Transcribe empty blocks

        Fill in every block that has no text yet, such as blocks drawn on the timeline or marked with this off. Z undoes it.

        Whisper understands English. It hears everything in a block, so dialogue or lyrics under the narration can come out too: if your file has a description track on its own, choose it with T. Names are often misspelled, so check them. The transcribing guide covers all of it.

        Check for updates?

        Scribecue can check GitHub once a day and tell you when a new version is out.

        GitHub sees the request and your IP address, like any website visit. Nothing about your files or text blocks is sent. If you say no, Scribecue never contacts anything outside your computer.

        You can change this later by clicking the version number in the bottom right.

        How to update

        If you got Scribecue with git clone, run these in the Scribecue folder:

        git pull
docker compose up -d --build

        If you downloaded a zip, download the latest release, replace the old folder with it, and run docker compose up -d --build inside it.
